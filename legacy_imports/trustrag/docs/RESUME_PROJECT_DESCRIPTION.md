# TrustRAG 项目简历描述

## 版本一：技术深度版（适合高级工程师/架构师）

**TrustRAG - 工业级金融证据检索增强生成系统** | Python, FastAPI, React, Pydantic

**项目描述**：
设计并实现了一个面向金融合规场景的高精度 RAG 系统，通过认知隔离架构和失败分类学设计，实现了数学上可证明的零幻觉保证。

**核心技术亮点**：
- **认知隔离架构**：设计并实现了 LLM 仅作为语言渲染器的架构，确保数值提取完全由确定性规则完成，数学上保证零幻觉
- **失败分类学驱动设计**：定义了 6 类高风险失败模式（F1-F6），将系统优化目标从"提升平均准确率"转向"系统性压制高风险错误"
- **风险驱动的资源调度**：实现了基于查询风险级别的动态资源分配，低风险查询走 FastPath（0 LLM，<50ms），高风险查询多轮仲裁验证（200-500ms）
- **多策略检索引擎**：实现了 MCU（Micro/Base/Macro）三层索引架构，支持稀疏检索、稠密检索、混合检索和重排序
- **证据仲裁系统**：设计了多源证据冲突检测与权威性排序机制，确保 10-K 等权威来源优先于新闻/PPT

**工程实现**：
- 构建了完整的评估框架，支持一键生成 JSON+HTML 评估报告，覆盖延迟、吞吐、成本、准确率、检索质量等 10+ 类指标
- 实现了多租户数据隔离、审计日志、性能监控、异常处理等企业级特性
- 设计了配置热加载、批量摄入自动化、场景模板等运维友好功能
- 前端实现了证据链可视化、仲裁理由展示、查询历史回溯等可追溯性功能

**技术栈**：
Python, FastAPI, React/Next.js, Pydantic, TypeScript, Docker, 向量检索, OCR, LLM API

**项目成果**：
- 实现了数学上可证明的零幻觉保证（所有数值必须来自已验证证据）
- 建立了完整的评估体系，支持自动化回归测试和红线规则检查
- 系统支持多租户、审计追溯、性能监控等企业级需求
