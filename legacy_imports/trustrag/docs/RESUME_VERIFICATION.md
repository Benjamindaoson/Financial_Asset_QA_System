## 建议的简历修改版本

### 修改版（更准确）

**TrustRAG —— 面向可靠性优先场景的 RAG 基础设施**

**项目背景**：
针对金融、医疗、政务、法律等"错误零容忍"场景，主导设计并实现了一套确定性优先的 RAG 基础设施。通过异构数据重组、智能路由分流与自动化风控闭环，系统性解决了通用 RAG 在生产环境中 "数据不全、响应太慢、答案不准" 的根本难题，将概率性的 LLM 输出转化为可审计的工程级决策系统。

**核心工作**：

• **构建多模态数据摄取与结构还原管道**
  针对 PDF / 表格 / 图片 / HTML 等异构数据中的格式混乱、表格破碎、噪声干扰问题，设计 "MinerU + PaddleOCR" 双塔解析架构与 Dual-Pass 清洗流程。自研跨页表格愈合算法，基于表头指纹（Jaccard 相似度阈值 0.7）与页码连续性自动重组断裂表格，在复杂财报测试中显著提升长表格结构完整性，有效解决上下文丢失问题。

• **设计查询感知的动态路由执行架构**
  针对传统 RAG "杀鸡用牛刀"导致的低效问题，设计两级分流路由方案，将查询分为 FastPath（结构化查库）与 Full RAG（检索+生成）两类路径，FastPath 无需调用 LLM。通过 FastPath 处理高确定性查询，显著降低响应延迟和 Token 成本。

• **构建全链路纵深防御体系，消除多维幻觉**
  针对 LLM 捏造数据、时空错乱、多源冲突等问题，建立事前-事中-事后三层防御机制：通过证据绑定强制核对每个回答的原文锚点实现数值幻觉防御；开发期间归一化机制支持对齐查询中的 "YoY/QoQ" 与数据源时间口径实现时空幻觉防御；引入基于信源权威等级的确定性裁决规则（如 10-K > News）实现多源冲突仲裁，在测试用例中所有预设冲突场景均被正确识别与消解。

• **落地不依赖 Prompt 的确定性风控策略**
  通过准入策略过滤低信源数据，并在生成前执行规则化拒答校验。在包含高风险越界用例的基线评测中，所有越界查询均被正确拒答，有效避免模型捏造关键事实。

• **构建针对金融场景的失败模式驱动评测体系**
  摒弃 BLEU/ROUGE 等泛化指标，针对金融研报场景自主设计了数值精度、引用有效性、拒答正确性等评测维度。定义包含 F1（数值幻觉）、F6（不安全回答）在内的 6 类 Critical 失败模式，建立了完整的自动化评估框架，支持 0.01% 相对误差容忍度的数值校验，并将 Critical 失败纳入 CI/CD 熔断标准，确保核心指标零退化。
